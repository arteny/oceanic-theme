# Oceanic Theme for Visual Studio 2022 and 2026

[Download](https://marketplace.visualstudio.com/items?itemName=pritompurkayasta.oceanicplustheme)

The theme keeps its existing editor and legacy UI colors for Visual Studio 2022, and adds Visual Studio 2026 Fluent `Shell` and `ShellInternal` colors so modern tool windows and other shell surfaces use the Oceanic palette.

To build the VSIX, use Visual Studio with the Visual Studio SDK/Extensibility tools installed. The build compiles `Oceanic.VS2026.xml` with the VSIX Color Compiler and includes the resulting package definition in the extension.
